# Data

Use this directory for local development metadata and evaluation manifests.

Do not commit private product images, API keys, personal information, or
unreviewed legal interpretations. Evaluation examples must have verified field
values and expected outcomes before they are used to report accuracy.

## Original dataset requirements

The project dataset must be independently collected, permissioned, officially
published, or clearly licensed for this work. For every example, keep
provenance, permission or license, collection date, product category,
annotated regions, verified field values, annotator/verification details, and
image-condition metadata.

Keep model annotations separate from human-verified legal-rule outcomes. Do not
use a copied dataset or private image without documented permission. If the
provenance is unknown, the example cannot be used for training or reported
evaluation.

Every dataset-schema or collection-policy change must be recorded in the root
`README.md`.
